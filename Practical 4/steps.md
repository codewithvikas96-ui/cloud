
# Cloud Practical – Using Google Drive as STaaS (Storage as a Service)

Aim: To use Google Drive as Storage as a Service (STaaS) by creating a file, storing it in the cloud and sharing it with other people.

Requirements:

- Google account (Gmail)
- Internet connection
- Google Drive

1. Open Google Chrome.
2. Visit [https://drive.google.com/](https://drive.google.com/?utm_source=chatgpt.com)
3. Sign in using your Gmail account.
4. You will see the Google Drive dashboard.

## Part 2: Create a File

[How to add files to Google Drive](https://images.openai.com/static-rsc-4/XUvMzr6zGvl9lQ_K8xcVf5j3Ny45H7HU2AxVAZQQAY3TNSW3MDwy16oqIF5jhfRkXvveClXP41UGcEYAPhqYWob6WLcHwdX0xa0mnFiznxjFhXXLxig1M5lf--Wham6KjlTWYnkF44O5DfZX8o5NQFzVLyj0wiVG0TfIfbMuuDE?purpose=inline)

[zapier.com](https://zapier.com/blog/how-to-add-files-to-google-drive/?utm_source=chatgpt.com)

1. Click on the + New button on the left side.
2. Select Google Docs.
3. A new document will open.
4. Click on Untitled document at the top.
5. Enter a file name, for example, `Cloud_Practical`.
6. Write some content inside the document.

Example:

```
Cloud Computing Practical

Name: Student
Subject: Cloud Computing

Google Drive is an example of
Storage as a Service (STaaS).

It allows users to store files
online and access them from anywhere.
```

7\. Google Docs automatically saves your document to Google Drive.

## Part 3: Share the File with Specific People

[Basic Use of Google Docs | utelecon](https://images.openai.com/static-rsc-4/XOmbPycEZd7gWAous7M23JRP150LvvFt1zAeqG40Szs9f0nbiKgWFki66WRbCXUZkDMxxh8KY-hrze4fghSwsD3XOZS9e88YfbYfcBm58iVIju91_5qaRhhPE5a9Ze9x6anNTnSia93KxfbTrI2yzGCjzfNdthpFhqVES25wyz0?purpose=inline)

[utelecon.adm.u-tokyo.ac.jp](https://utelecon.adm.u-tokyo.ac.jp/en/articles/google-document/?utm_source=chatgpt.com)

1. Open the created document.
2. Click the Share button in the top-right corner.
3. A sharing dialog box will appear.
4. Under Add people, groups, and calendar events, enter the Gmail address of the person.
5. Select the required access permission.

| Permission | Description                        |
| ---------- | ---------------------------------- |
| Viewer     | Can only view the file             |
| Commenter  | Can view and add comments          |
| Editor     | Can view, edit and modify the file |

6\. Click Send.

The selected person will receive an email invitation to access the file.

## Part 4: Share the File Using a Link

[How To Share Your Google Drive With Someone? Step-By-Step Guide](https://images.openai.com/static-rsc-4/vDG0Uf3_HcTVNqelPxX1dNWRFlunPWvj9nXn32TKfjkPK5DsGDb6zICYmRMNhH2JZmXIlYC7FnR5pmtLPGKmMlR7wroIgoSmR-HRsHKIxan4ecTpBRSohNI8hU_YXIg1sPwvHtqrh4UeXAkImXtqoRcYzEvQhqGSQX1XNOLu6ac?purpose=inline)

[electronicshub.org](https://www.electronicshub.org/how-to-share-google-drive/?utm_source=chatgpt.com)

1. Open the document.
2. Click Share.
3. Find the General access section.
4. By default, it is set to Restricted.
5. Click on Restricted.
6. Select Anyone with the link.
7. Select the required permission (Viewer, Commenter or Editor).
8. Click Copy link.
9. Click Done.
10. Send the copied link to other people through WhatsApp, email or any messaging platform.

Now people with the link can access the file according to the permission you selected.

Practical completed

## Part 5: Verify File Sharing

1. Open Google Drive.
2. Locate your created document.
3. Right-click on the document.
4. Select Share → Share.
5. Check the people who have access to the file.
6. Verify their assigned permissions.
